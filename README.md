# ASP.NET Core Concepts Lab

A collection of small, focused ASP.NET Core projects created to understand and practice core framework concepts.

The goal of this repository is to learn ASP.NET Core through practical examples rather than theory alone.

## Purpose

This repository serves as:

- Learning reference
- Interview preparation resource
- Revision guide
- Hands-on ASP.NET Core playground


## Topics Covered

### Fundamentals
- Middleware
- Dependency Injection
- Configuration
- Logging
- Exception Handling

### Authentication & Authorization
- Cookie Authentication
- JWT Authentication
- OAuth
- ASP.NET Core Identity
- Claims
- Roles
- Policy-Based Authorization

### Performance
- In-Memory Caching
- Distributed Caching
- Response Caching

### APIs

- Rate Limiting
- Health Checks

### MVC Concepts

### Filters

### Background Processing

### Real-Time Communication

### File Handling

- File Download

### Architecture

- Repository Pattern
- Unit of Work
